Three things the page-64 audit needs from you

The audit of Room Care against page 64 (roomcare/docs/page64-audit.md) ended with cells that only you can settle. A and B are choices: every option is drawn, including the one that is built today. C is a set of records: the frames moved onto rulings you have already made. Approving them changes nothing that is running. Each option is a real window of 01 or 02, changed only where it says.

Out of scope here: APPS-Q43's card half (small controls inside a card) is still open with you, and A does not settle it. C8 (a table row that opens something) is with the planner as APPS-Q50.
