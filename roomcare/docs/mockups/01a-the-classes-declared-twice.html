The classes the screens page declares twice

01-the-roomcare-screens.html declares eleven classes twice. Three are redeclared with identical values and change nothing — .btn, .note, .num. Eight differ, and in every one the difference is size and spacing — no colour changes. The second declarations arrived with redline 5 (the Room states frames, 2026-09-13) and are not scoped to those frames, so a browser applies them to every frame on the page: the locked page renders today with the second set.

Which set the build follows, per class — measured against roomcare/ui/chrome/styles.ts at 4959365, not assumed: the first for .pill .mono .tag .tile .tilegrid, the second for .chip .strip, and neither exactly for .legend.
