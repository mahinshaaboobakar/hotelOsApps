E · what this round found

In Jobs, and fixed in the round

  • The organisation was nowhere. A module call names a property and never an organisation, and the catalogue is the organisation's. Curating now asks Master Data which organisation the property is in, rather than letting a bundle say whose catalogue it edits.
  • A denial said too much. The module surface answered a PermissionDeniedException with the service's own sentence, which names the permission and the resource that the gRPC surface deliberately withholds. It says "permission denied" now.
  • Resolutions had no ids. The catalogue read carried names, and resolving names an id — so the screen could not have sent what the service stores.
  • A held row's own expectation was wrong. One of the ten wanted the refused permission named in the message; the platform withholds it on purpose. That is what a row held on the fourth verdict costs: it was never run, so nobody found out.

In the platform, reported — and one closed the same day

  • A denied capability arrived as 500. The envelope answers with Results.Forbid(), which needs an ASP.NET authentication scheme that neither the SDK nor hello-hotel registers — so a person who simply lacks a permission was told the system was broken. Never met before, because the exemplar's proof stubbed the .NET side. Jobs registers a scheme that authenticates nobody so a forbid has somewhere to go.
  • An invalid token still arrives as 500. JwtCallerAuthenticator throws AuthenticationFailedException, and the envelope's catch is around the handler only, not around authentication — while its own table already says 401 for exactly that. Mapped in Jobs, reported there.
  • A body sent chunked is read as no body at all. The envelope decides whether parameters were sent by reading Content-Length. A caller that streams its JSON loses every parameter silently. Jobs' round sends a length, as the Shell does; reported so a bundle that does not is not the way it is found.
  • Closed at the source while this round ran: 755ee02 gave the envelope the interceptor's status table, so an application's refusals cross that hop as themselves. Jobs' own mapping middleware was deleted the day it landed rather than left to disagree with it.

G · one thing for the owner to rule on

A form that acts looks different from a form that was drawn. The locked frames show every field already filled with an example — a summary written, a room chosen, a resolution picked — which is how a drawing says what a field is for. A form a person fills in starts empty. The labels, the hints, the controls and the order are the frame's; the example values are gone, replaced by placeholders in the frame's own words where the frame had them. This is the only place the build now departs from the drawings on purpose, and it is put here rather than absorbed quietly.
